Como Conectar esta Planilha ao Power BI / Python Automaticamente

Existem duas maneiras principais para integrar a planilha !Importações.xlsx de forma dinâmica com sistemas de Business Intelligence, sem intervenção manual diária:

Opção A: Script Python Automatizado (ETL)

Lê a planilha, converte valores em formato pt-BR/US de forma segura e atualiza um banco SQLite (pode ser trocado por Postgres/SQL Server).

Opção B: Conexão Direta no Power BI Desktop

Conecte via Power Query usando pasta de rede ou SharePoint/OneDrive para atualização agendada no Power BI Service.

Script ETL Python (pandas & sqlite3) pipeline_importacoes.py 
import re
import sqlite3
import pandas as pd

def parse_number(value):
    if pd.isna(value):
        return 0.0
    if isinstance(value, (int, float)):
        return float(value)
    text = re.sub(r"[^\d,.-]", "", str(value)).strip()
    if not text:
        return 0.0
    if "," in text and "." in text:
        if text.rfind(",") > text.rfind("."):
            text = text.replace(".", "").replace(",", ".")
        else:
            text = text.replace(",", "")
    elif "," in text:
        parts = text.split(",")
        if len(parts) == 2 and len(parts[1]) <= 2:
            text = parts[0] + "." + parts[1]
        else:
            text = text.replace(",", "")
    try:
        return float(text)
    except ValueError:
        return 0.0

def process_excel_to_bi(file_path, sheet_name=0):
    df = pd.read_excel(file_path, sheet_name=sheet_name, engine="openpyxl")
    if "Valor USD" not in df.columns:
        raise KeyError("Coluna 'Valor USD' não encontrada. Ajuste o mapeamento.")
    df["Valor_USD_Clean"] = df["Valor USD"].map(parse_number)
    if "Peso (kg)" in df.columns:
        df["Peso_Kg_Clean"] = df["Peso (kg)"].map(parse_number)
    conn = sqlite3.connect("bi_importacoes.db")
    df.to_sql("tb_importacoes", conn, if_exists="replace", index=False)
    conn.close()

if __name__ == "__main__":
    process_excel_to_bi("!Importações.xlsx", sheet_name="!Importações")
